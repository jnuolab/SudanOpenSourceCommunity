## 📖 عن المشروع

هدفنا أن نجمع كل المشاريع السودانية مفتوحة المصدر في مكان واحد، لنسهّل على المطورين اكتشافها والمساهمة فيها، ولنعرّف بالمواهب التي تقف خلفها.

## 🎯 الأهداف

- توثيق المشاريع السودانية مفتوحة المصدر في قائمة واحدة منظمة
- إبراز المؤسسين والمساهمين وإنجازاتهم
- ربط المطورين السودانيين ببعضهم وبالمشاريع التي تحتاج مساهمين
- تشجيع ثقافة المصدر المفتوح في السودان

## ➕ كيف تضيف مشروعك؟

1. اعمل **Fork** للمستودع.
2. أضف مشروعك كسطر جديد في الجدول أعلاه.
3. افتح **Pull Request** بعنوان واضح، مثل: `إضافة مشروع: اسم المشروع`.

**شروط القبول:**
- المشروع مفتوح المصدر برخصة معروفة.
- المشروع سوداني (من تأسيس أو مشاركة سودانيين، أو يخدم السودان).
- يحتوي على README يشرح فكرته.

يمكنك أيضًا فتح **Issue** باقتراح مشروع تعرفه.

## 🤝 المشاركة

نرحب بكل أنواع المساهمة:

- تحسين التوثيق والتصميم
- نشر المبادرة بين المطورين
